# Served in place of the production robots.txt on Netlify deploy previews and
# branch deploys - see the context rules in netlify.toml.
#
# A preview is a byte-identical copy of the site on a different hostname. Left
# crawlable it becomes a duplicate of every page, competing with the real one,
# so Phase 13 requires staging to be uncrawlable and unindexable. The
# X-Robots-Tag header in netlify.toml is the half that actually keeps it out of
# the index; this file is the half that keeps crawlers from fetching at all.

User-agent: *
Disallow: /
